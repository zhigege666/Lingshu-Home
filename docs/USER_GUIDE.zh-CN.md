# 使用手册

[English](USER_GUIDE.md) | **简体中文** | [项目说明](../README.zh-CN.md)

本手册对应 **Lingshu-Home 0.0.4**，按实际界面介绍初始化、日常维护、首页配置和外部接入。新实例可在启动时指定语言，或通过首次页面选择一次；保存后整个实例沿用。安装参数见 [README](../README.zh-CN.md)，接口契约见 [API.md](API.md)，验证的实际范围见 [tests/README.md](https://github.com/zhigege666/Lingshu-Home/blob/v0.0.4/tests/README.md)。

应用的首页、后台、账号/初始化、启动画面、页面品牌和浏览器标签页统一使用玉绿色折带房屋标识。本手册已覆盖专用可视化编辑器、经典/iOS 主题和图标库。所链接的上一轮 Logo/布局截图及中文 192 个、英文 218 个浏览器断言属于历史记录，本轮实际验证单独记录在 [tests/README.md](https://github.com/zhigege666/Lingshu-Home/blob/v0.0.4/tests/README.md)。

## 1. 启动并初始化

按[快速开始](../README.zh-CN.md#快速开始)安装 **Docker 镜像或 Linux amd64 发行包**。程序发行包自带前端，无需 Go 或 Node.js。两种快速开始方式都使用 SQLite，并将数据库与实例密钥保存在可替换程序之外。

如果选择源码 Compose 方式，先按 README 取得对应版本源码，再在仓库目录执行：

```bash
LINGSHU_LANGUAGE=zh-CN docker compose up -d --build
docker compose ps
```

在运行 Home 的机器上打开 `http://127.0.0.1:5180`。示例只绑定宿主机的回环地址；其他设备需要使用管理员配置的对外地址或反向代理地址。首页、后台、API 和 MCP 由同一服务提供。

如果看到**初始化 Home**：

启动时未指定语言的新实例会先显示双语选择页，选择简体中文或 English 并确认，成功保存后才进入初始化表单。已明确指定或已有保存语言时跳过选择页。语言在此时立即保存，即使账号初始化稍后才完成也会保留。

1. 填写**站点名称**并选择访问方式。站点名称与各个页面名称独立。默认**公开浏览**允许访客读取已发布共享内容，维护需要 Owner；个人空间仍然私有。
2. 需要账号的模式会要求创建 Owner，没有默认管理员账号或密码。用户名为 3–40 位英文字母、数字或 `. _ -`，密码为 10–128 个字符，显示名称选填。**完全开放**中的**同时创建管理员（可选）**默认不勾选；勾选后可保留匿名导航维护，同时创建账号。
3. 如需示例，勾选**填充示例导航**，可以展开**预览将添加的网站**。内容包自动匹配已保存的实例语言，不能另行切换。默认不勾选，示例只进入共享空间，以后可以编辑或删除。
4. 点击**创建我的 Home**。创建 Owner 后自动登录。完全开放和公开浏览进入共享空间；私人模式选择示例时进入共享空间，否则进入 Owner 的个人空间。
5. 通过**管理中心**维护内容。有维护权限的空白首页还提供**添加第一个链接**和**导入浏览器书签**，直接打开当前空间对应的后台流程。

如果设置请求失败或结果不明确，可以使用**重新检查初始化状态**读取服务端当前的初始化与登录状态。此操作不会重新提交表单，也不会使用保留的密码自动登录。尚未初始化时继续保留表单；已经完成时按实际状态进入首页或登录页。

如果已有实例直接显示首页或登录页，说明已经完成初始化，应继续使用其现有账号与数据。Home 不会自动读取个人浏览器数据。

### 选择实例语言

[查看上一轮英文首页实拍](https://github.com/zhigege666/Lingshu-Home/blob/v0.0.1/assets/screenshots/home-brand-en-2k.png)。这张历史图片早于可视化编辑器和 iOS 主题，已有分类和书签名称仍保留原文。

一个实例统一使用 `zh-CN` 或 `en`，覆盖首页、初始化、登录与管理界面。**0.0.2 只确定并保存一次语言**，可选示例内容也跟随它；之后没有页面内切换，也不会被浏览器语言覆盖。下表的启动配置只在实例尚未保存语言时决定首次语言。

| 部署方式 | 以英文启动的示例 |
| --- | --- |
| 正式 Docker 镜像 | 在 README 的完整 `docker run` 命令中使用 `-e LINGSHU_LANGUAGE=en` |
| Linux 发行包，在解压目录执行 | `./lingshu-home --language en --data-dir "$HOME/.local/share/lingshu-home"` |
| 源码 Compose / SQLite | `LINGSHU_LANGUAGE=en docker compose up -d --build` |
| 源码 Compose / PostgreSQL | `LINGSHU_LANGUAGE=en docker compose -f compose.postgres.yaml up -d --build`，同时保留数据库环境配置 |
| 开发脚本 | `python3 scripts/dev.py start --language en` 或 `python3 scripts/dev.py run --language en` |
| 构建后的服务，在仓库根目录执行 | `./dist/lingshu-home --language en` |

需要简体中文时将示例中的 `en` 改为 `zh-CN`。尚未保存语言时，显式 `--language` 优先于 `LINGSHU_LANGUAGE`。未指定或空值会让新实例先进入语言选择；开发脚本和 Compose 不再暗补中文。确认后先将语言写入实例数据库，再进入账号表单，刷新页面或重启都会沿用。若确认返回错误，应留在选择页重试或读取当前状态，不能假定已经保存。

一旦确认，修改启动参数或容器环境不会切换语言；与保存值冲突的有效参数会产生警告，服务保留原语言并继续运行。之后没有用于修改语言的页面或设置接口。示例内容显示为匹配的中文/英文网站预置，仅保留预览，不再选择第二次。已有名称和自定义文字不会被翻译或重命名。

**升级已初始化的 0.0.1 实例：**先备份数据库和密钥，并在首次启动 0.0.2 时保留原本使用的 `--language` / `LINGSHU_LANGUAGE`，英文实例尤其要保留 `en`。应用迁移 007 后的首次启动保存这一语言，未指定时保留旧默认 `zh-CN`；已有实例不再显示语言选择页。应用过 007 的数据库需要匹配的新程序，退回 0.0.1 必须恢复升级前的数据库和密钥备份。

**与 0.0.1 的兼容性：**旧版本没有首次语言页与持久化语言，示例包可以独立选择。从 0.0.2 开始，界面与示例统一跟随已保存的实例语言。

### 选择访问模式

| 界面选项 | 模式值 | 浏览与维护规则 |
| --- | --- | --- |
| 完全开放 | `open_edit` | 已发布的共享导航允许免登录浏览、维护；初始化可勾选同时创建 Owner，也可不创建账号。 |
| 公开浏览 | `public_read` | 已发布的共享导航免登录浏览；Owner 登录后维护共享内容和自己的个人空间。 |
| 私人导航 | `private_single` | 浏览和维护都需要 Owner 登录。 |
| 多人空间 | `private_multi` | 用户登录后使用；Member 各自维护个人空间，Owner 维护共享空间并管理账号。 |

初始化默认选择**公开浏览**。个人空间在所有模式下都保持私有，Owner 不能进入其他人的个人空间。自助注册是单独开关，默认关闭，只能在多人空间模式下开启。

数据库在部署时选择，初始化页面不提供数据库切换。SQLite 为内置默认；外置 PostgreSQL 使用独立的 Compose 文件。改变 provider 不会转换已有数据，选择或更换前请阅读 [存储说明](STORAGE.md)。

### 免账号初始化后怎样增加管理员

如果当前是没有 Owner 的**完全开放**模式，进入**访问与账号**，勾选**同时创建首个管理员（可选）**，填写用户名、显示名称（选填）和密码，再点击**保存访问设置**。可以保持完全开放，也可以同时选择需要账号的模式；无需先切换模式再切回来。创建成功后自动使用这个 Owner 会话，保留已有共享内容。完全开放仍允许匿名导航维护，账号可用于集成和其他需要身份的操作。

外部数据源配置、Home 访问令牌和 MCP 始终要求账号。允许匿名维护本地导航不会开放凭证管理。已经存在 Owner 时，全局访问设置由 Owner 维护。

## 2. 选择空间和管理入口

通过首页**管理中心**进入，或在实例地址后加 `/#/admin`。后台标题右侧的**当前空间**决定本次操作归属；首页有多个可用空间时也会出现空间选择。添加链接或导入书签前，先确认空间。

0.0.4在此浏览器、此站点地址下，按账号与匿名身份分别记住上次成功打开的空间；保留浏览器数据时，可跨刷新、独立新标签页和浏览器重启沿用。登录后，通过空间选择器旁的**默认打开空间**选择**记住上次空间**，或指定固定的可访问空间。选择**记住上次空间**会清除固定默认，不会立即切换当前显示的空间。

当前标签页中已经成功打开的手动选择优先，刷新后仍沿用；没有手动选择时，依次采用固定默认、上次成功访问、服务端默认或首个可访问空间。退出登录会清除当前标签页的手动选择，但保留该账号的浏览器偏好供下次登录使用。空间已删除或权限失效时会清除无效偏好；请求失败不会把失败目的地记为上次成功空间。浏览器不允许存储时，登录和空间切换仍可使用。这些偏好仅属于**此浏览器中的当前账号**，不跨设备同步，也不改变账号权限。示例只在共享空间，空白且可维护的首页仍可直接**添加第一个链接**或**导入浏览器书签**。

| 菜单 | 主要用途 |
| --- | --- |
| 链接管理 | 新增、编辑、搜索、删除本地链接 |
| 分类管理 | 设置父子分类、图标和排序 |
| 布局与主题 | 页面外观、预设、分类导航、积木和数据绑定 |
| 导入与导出 | 导入浏览器书签、导出当前空间、修改空间名称 |
| 数据源与 MCP | 外部源、GitHub Traffic、个人访问令牌 |
| 访问与账号 | 站点名称、访问模式、注册开关与无 Owner 时的首个管理员创建 |
| 网络设置 | 自动选择内外网入口，以及 Owner 管理的服务端代理 |
| 成员管理 | Owner 在多人模式下创建和管理 Member |
| 关于 Home | 检查后端与前端版本、项目和许可信息 |

管理后台使用固定高度工作区。链接和分类列表在表格内部滚动，页面标题、搜索、操作按钮和分页栏保留可见；设置页面在自己的内容区滚动，布局编辑器的保存、取消固定在底部。不会因为逐次加载表格行而无限拉长整个页面。

### 分页与搜索

链接、分类默认每页 **25 条**，底部可以切换 **25 / 50 / 100 条**，并使用首页、上一页、下一页、末页按钮。搜索、切换空间或管理栏目会回到第一页；删除后如果当前页已不存在，会回到有效页。

这里是**浏览器已加载的授权导航快照分页**，控制每页实际挂载的表格行数；不是后端按页取数，也不是滚动追加的“加载更多”。链接列表搜索名称、主 URL、描述和标签；分类搜索包含父分类路径。其他窗口修改了数据时，可刷新当前页面重新读取。

## 3. 维护分类和链接

### 分类

1. 进入**分类管理 → 添加分类**。
2. 填写**分类名称**，从内置图标或已导入图标库中选择，操作见下文。
3. **父分类**选择**顶层分类**，或指定一个已有分类。编辑时不能选择自己或自己的后代作为父分类。
4. 设置**排序**并保存。数字越小越靠前；可以使用 10、20、30，方便以后插入分类。

点击铅笔按钮可重命名、修改父分类或排序。修改父分类会改变数据层级；首页切换树形或平铺只是展示同一层级，不会移动分类。最终层级最多 32 层。

分类中仍有链接或子分类时不能直接删除。先将链接移到其他分类或**未分类**，再移动或删除子分类，最后点击删除并确认。当前版本没有回收站恢复流程。

### 链接与项目多个入口

1. 进入**链接管理 → 添加链接**。
2. 填写**链接名称**和完整的 `http://` 或 `https://` **主入口 URL**，选择分类或**未分类**。
3. 按需添加描述和逗号分隔的标签。图标默认使用自动获取，也可选择内置/导入图片作为手动图标。
4. 常用项目勾选**加入常用收藏**，并设置排序。
5. 需要自动选择的地址放在**内外网访问**中，使用**添加内网入口**或**添加外网入口**，填写名称、完整 URL 和只读探测路径。文档、管理页等手动入口放在**其他入口 → 添加入口**；这些未标记入口不参与自动选路。每条链接的网络入口与其他入口合计最多 12 项。跨域探测需要服务允许 Home 的 CORS 请求，无法确认时保留外网/主入口回退；详见[网络设置](#网络设置与内外网访问)。
6. 点击**保存链接**。

管理表格保持紧凑：显示主 URL、前两个标签、前两个附加入口，其他项用数量提示。悬停数量可查看摘要，打开编辑器可查看和维护全部内容；列表简写不会丢弃保存的数据。

点击铅笔编辑，删除按钮旁的确认浮层用于移除该链接及其附加入口；链接和分类删除默认聚焦取消，可用 Escape 关闭。长表单保持标题、关闭按钮和底部操作区可见，中间内容滚动；链接基本信息与图标在宽屏下分为两列。只支持 HTTP/HTTPS，不支持可执行书签、浏览器内部地址和本地文件地址。

首页有维护权限时，也可以直接点星标更新**本地链接**的收藏状态。外部快照中的链接由来源维护，不能用本地链接的星标操作改写。收藏区和完整导航中同时出现的项目，是同一条链接被两处展示。

### 批量整理链接

导入完成后，在**链接管理**中搜索需要整理的链接：

1. 每行复选框选择单个链接；表头复选框只选择**本页**。翻页或调整每页数量会保留当前选择。
2. **选择全部筛选结果（数量）**会选中当前搜索结果，一次最多 500 个；结果超过 500 个时先缩小筛选范围。工具栏始终显示**已选数量**。
3. 选择**移动分类**、**维护标签**或**设置收藏**。分类可以选**未分类**；标签可以添加或移除，不会替换其他标签；收藏可以批量设置或取消。
4. 在弹窗确认当前空间、选择数量和预计修改数量，再点击**应用到 N 个链接**。已经符合条件的链接保持不变。
5. 操作完成后读取新列表并清除选择。搜索条件变化、刷新列表、切换菜单/空间/身份以及权限失效也会清除选择。

每个链接最多 32 个标签，每个标签最多 40 个字符。标签用逗号分隔、去除首尾空白并精确匹配。如果另一窗口、导入或自动图标处理使列表版本变化，弹窗会提示本次没有写入，并要求**刷新并重新选择**；不会自动覆盖新数据。这一批会全部成功或全部回滚。

批量操作直接更新导航数据，不属于页面草稿撤销历史。整理操作只修改选择的分类、标签或收藏字段，保留 URL、附加入口、图标及图标自动/手动模式。0.0.4还提供**批量删除**：按钮旁确认浮层显示当前空间和选择数量，点击**删除 N 个链接**后永久移除所选链接及其其他入口。提交前可取消、按 Escape 或点击浮层外关闭；请求处理中不能重复提交。若删除已成功但列表刷新失败，界面会明确提示已完成删除并要求刷新，不恢复可重复删除入口。

### 选择或导入图标

链接和分类表单共用图标选择器。0.0.4 的**内置**提供 120 个离线 Lucide 线性图标，按 8 组浏览，由 0.0.2 的 30 个扩充而来。可在**图标分组**中浏览 AI、开发、服务器、办公学习、影音设计、生活服务、资讯社区和常用图标，也可搜索中英文名称、技术名称，以及 NAS、Docker、AI、知识库、video 等关键词。输入搜索会覆盖全部分组，选择分组会清空搜索；**清空图标搜索**恢复全部结果。每页显示 24 个图标及其名称，上方保留当前选择的预览。

**使用默认图标**将表单恢复为链接/分类的默认图标。选图标只修改表单草稿，需点击**保存链接**或分类保存操作才会应用。原有分类、链接和旧图标不会被自动替换。

使用自己的图片或图标集合：

1. 确认当前空间，打开图标选择器的**导入**页签。
2. 选择单张 `.png`、`.jpg`/`.jpeg`、受支持的静态 `.svg`，或符合 [ICONS.md](ICONS.md#import-a-pack) 的 Schema 1 `.json` 图标库。
3. 检查**图标库名称**、选填的**来源网址**和必填的**许可或权属说明**。第三方素材保留真实原始许可；来源网址只记录出处，导入不会访问该网址。
4. 单图点击**导入并选用**，多图点击**导入图标库**。单图会自动选入表单草稿，多图在**图标库**页签继续选择。
5. 保存链接/分类表单，应用所选图标。

单图最多 256 KiB、512 × 512，SVG 输入另限 64 KiB，并要求正值且有界的 `viewBox`。每个图标库有 1–64 张图、解码后总计最多 4 MiB，每个空间最多 32 个图标库。服务端检查真实格式并重新编码位图；SVG 只接受静态几何，不接受脚本、外部引用、文字、渐变或嵌入图片。复杂 SVG 可先转成 PNG，不接收 ZIP、图标字体或 CSS 包。完整空间限额和 JSON 示例见 [ICONS.md](ICONS.md)。

在**图标库**选择已有库，可搜索、查看**来源与许可**或刷新列表。删除需要点击内联确认；如果删除最后保留的图片会使已保存链接、分类、页面或外部快照失效，服务端会拒绝，应先替换那些引用。如果另一图标库或网站缓存仍保留相同图片，可保留共用图片并删除当前库。

### 获取网站图标

**访问与账号 → 自动获取网页图标**默认开启。新增链接和导入浏览器书签默认使用自动模式：先保存书签，再在后台获取受支持的网站图标。在链接管理点击**刷新列表**，或在仅有导航组件的首页点击**刷新内容**，即可读取已完成的结果；不会为此增加首页自动轮询。

链接表单区分自动与手动模式。选用内置图标、图标库图片、**使用默认图标**或主动获取到的图片，都会把该链接设为手动模式，后台任务不能覆盖选择。需要恢复自动获取时，在链接表单切回自动并保存。升级前已有链接和离线预置内容保留原图标。

关闭实例开关会清理待办，并取消/丢弃正在获取的自动结果，保留已保存图片；仍可主动获取网站图标。重新开启只影响之后的保存/导入，不扫描旧链接。已有 Owner 时由该管理员控制开关；无管理员的完全开放实例可直接配置。只切换图标开关不会使当前会话退出。

链接表单填入完整主入口网址后，点击**获取网站图标**。Home 请求网站的根地址，查找声明的图标与 `/favicon.ico`，校验后返回本地图标供选择；不会转发书签路径、查询参数或片段。保存链接后才会应用该选择。

普通访问者只加载 Home 自己提供、经过空间权限检查的图片，不会因为访客浏览时缺图就发起网站请求，也不使用 Google 等第三方 favicon 代理。0.0.4的自动和主动抓取均支持公网、可达内网及自定义端口的 HTTP/HTTPS 网站；原始主机可使用 RFC1918/ULA 地址或可解析的局域网名称，跳转或图标候选中的其他主机仍须为公网。Home 所在服务器/容器需要能解析并访问该服务，HTTPS 仍需通过系统证书校验。需登录或格式不受支持时可导入本地图标或用预制图标。支持 PNG、JPEG、受限静态 SVG 和有界的常见 ICO 编码，不保证接受所有网站的图标格式。获取失败或队列满时，书签仍正常保存，继续使用原图标或默认图标。

成功结果缓存 24 小时，初次失败缓存 30 分钟，刷新失败时保留上次成功的图片。过期后，再次保存符合条件的自动链接或主动获取可尝试刷新；时间到期本身不会发起任务。每个实例同时只运行一次远程图标获取，手动操作遇到繁忙提示时可等当前请求完成后再试。

图片内容和每个空间的网站缓存保存在 Home 所用数据库中。浏览器通过带权限重新验证的 HTTP 缓存复用图片，不把唯一副本放在浏览器存储里；清理浏览器数据或换设备不会删除服务端图片。空队列没有定时器，也不需要额外缓存服务。

**导入、确认删除图标库，以及网站缓存写入会立即保存到当前空间。**取消链接/分类表单只放弃这次图标选择，不会撤销图标库或缓存操作。这些动作遵守当前空间维护权限，包括**完全开放**模式的免登录维护，并保留浏览器 CSRF 检查；个人空间图标不会跨空间公开。

## 4. 导入 Chrome 书签

### 从 Chrome 导出文件

在桌面 Chrome 中打开菜单，进入**书签和清单 → 书签管理器**，再使用书签管理器自己的菜单**导出书签**，保存为 HTML 文件。路径以 [Google 官方导出说明](https://support.google.com/chrome/answer/96816?hl=zh-Hans)为准。

Home 只导入你明确选择的文件，不会连接 Google 账号同步，也不会自动读取浏览器配置目录。

### 在 Home 预览并导入

1. 确认当前空间。
2. 进入**导入与导出 → 选择书签文件**，或**链接管理 → 导入**。
3. 选择刚导出的 `.html` 或 `.htm` 文件。
4. **重复网址**选择**跳过重复项**或**保留重复项**；默认跳过。
5. 选择**导入到分类**。选**根目录**时从空间根目录还原文件夹结构；选一个分类时，导入结构放在该分类下面。
6. 点击**预览文件**，检查总数、无效项、重复项和文件夹路径。
7. 点击**确认导入**，查看新增和跳过数量，并回到分类、链接列表确认结果。

| 项目 | 实际规则 |
| --- | --- |
| 文件与数量 | UTF-8 书签 HTML 不超过 2 MiB、10,000 个链接 |
| 文件夹深度 | 导入后最多 32 层，包含所选目标分类原有的层级 |
| 预览 | 最多显示前 200 项；统计覆盖整个文件 |
| 重复识别 | 比较目标空间已有链接和文件前面条目的规范化 URL |
| 跳过重复项 | 保留已有链接，不通过导入更新它的名称、分类等字段 |
| 保留重复项 | 将安全有效的重复 URL 保存为独立链接 |
| 无效网址 | 单独计数，不成为新链接 |
| 更换文件或选项 | 旧预览会清空，需要重新预览后确认 |

“有效”数量包含同时被标记为重复的条目，不要把两项相加。预览不写入导航；导入时会重新解析文件并检查当前空间。整个文件被拒绝时，不会留下半份导入结果。使用跳过策略重复导入且没有新链接、文件夹时，导航版本不会前进。

其他浏览器如果提供兼容 Netscape 格式的 HTML，也可使用此入口。Home 的 JSON 导出文件不能交给 HTML 书签导入器。HTML 导出会将附加入口写成独立书签，再导入时不会自动恢复成原来的“一个项目多个入口”结构。

## 5. 配置首页

首页由数据绑定、组件和位置组合而成，修改布局不会重新分配或删除链接与分类。当前每个空间管理一个首页；首页可视化编辑器与后台布局编辑器保存同一份页面配置。第三方主题包安装和多页面管理属于后续能力。

### 直接在首页编辑

具有维护权限时，在首页点击**编辑页面**。普通站点头部替换为专用编辑工具栏，为页面拼装留出工作空间：

| 区域 | 操作 |
| --- | --- |
| 顶部工具栏 | 打开组件库、撤销/重做、预览、恢复、取消或保存，查看**未保存/未修改**状态 |
| 左侧 → 页面结构 | 选择页面外观、已有组件或页眉页脚槽位；隐藏和锁定组件仍列在其中 |
| 左侧 → 添加组件 | 新增组件，或选择页眉/页脚以编辑页面内容 |
| 中间画布 | 实时查看草稿，选中组件或页眉页脚六个槽位，包括空槽位 |
| 右侧属性 | 修改当前选中对象，不需要另开管理页面 |

编辑窗口较窄时，两侧面板改为抽屉，通过**添加组件**和**属性**打开。关闭抽屉或点击**返回画布**即可继续检查效果。关闭抽屉不会保存或丢弃内存中的草稿。

普通头部隐藏后，搜索框仍作为独立组件出现在画布中，可以选中编辑。分类导航也可以点击编辑标签，或从**页面结构**中选中。账号控件与普通站点身份头部仍由 Home 提供；可配置页眉页脚是另一组页面内容。

### 撤销、重做与保存边界

首页编辑工具栏和后台**布局与主题**底部都提供**撤销/重做**。主题、外观、组件、位置、数据绑定与页眉页脚内容都进入当前页面的草稿历史；后台的页面名称也包含在内。

- 一次拖动或缩放对应一步。连续输入在同一个焦点内、间隔小于 750 毫秒时合并为一步；离开输入框会开始新的一步。
- 最多保留 60 步。撤销后进行新修改会清除旧的重做分支；撤销回已保存内容时，页面恢复为无未保存更改状态。
- 使用 `Ctrl/⌘ + Z` 撤销、`Ctrl/⌘ + Shift + Z` 重做；Windows/Linux 也支持 `Ctrl + Y`。输入框保留浏览器自身的文字撤销；弹窗、首页预览模式、拖拽进行中和保存中不会抢用页面历史快捷键。
- 历史只存于当前编辑会话，不跨刷新、账号、空间或页面保留。成功保存、取消/恢复或载入服务器版本后清空历史。它不撤销书签导入、导航维护、图标或数据源记录的写入。
- **保存页面**仍是唯一提交草稿的动作。写入失败或出现版本冲突时保留草稿和历史；成功写入但重新读取失败时，会明确提示“已经保存”，保留新的版本号和已保存内容，后续编辑可以继续保存。

### 选择主题和页面外观

在**页面结构**顶部选择当前页面，**首页主题**提供两款内置主题：

| 主题 | 默认链接外观 | 视觉变化 |
| --- | --- | --- |
| **经典导航** | 图标与文字 | 经典导航的面板、间距细节和视觉样式 |
| **iOS 风格** | 应用图标 | 圆角图标容器、柔和背景和参考 iOS 的视觉层次 |

切换主题只改变保存的主题 ID，保留数据绑定、组件 ID、位置与锁定、页眉页脚内容、配色、密度和间距，不会重置页面或复制链接。两款主题支持相同的内置组件和六个页眉页脚槽位。主题作用于首页，后台、初始化和登录继续使用内置管理界面。

在**全局外观**设置**配色**、**内容密度**和**组件间距**，这些操作只修改草稿。修改页面名称仍在后台**布局与主题 → 页面与外观**中完成，页面名称与全局站点名分开保存。

后台的**当前主题**也可以选择同样的两款主题。**分组卡片/紧凑目录**是另一种操作：确认应用布局预设会替换草稿中的组件、绑定和位置，同时保留当前主题、自定义页眉页脚以及本地/外部来源数据。替换排列后应先预览，再保存。

### 添加并配置组件

1. 点击**添加组件**，选择搜索、分类导航、常用收藏、书签导航或 GitHub Traffic。当前空间先存在兼容的 GitHub Traffic 数据源后，才能添加 Traffic 组件。
2. 在画布或**页面结构**中选中组件，按需设置**组件标题**。
3. 使用**显示位置**切换允许的区域，用**上移/下移**在当前区域调序。分类导航支持顶部、左侧、右侧、底部或隐藏，不放入主内容网格。
4. 消费数据的组件可选**数据来源**。导航、收藏和分类接受兼容导航集合；Traffic 需要对应格式。搜索只筛选与它联动的组件，没有直接数据源选项。
5. 导航和收藏可分别设置**排列方式 → 卡片/目录**，再独立设置下文的**图标与文字**。
6. 有多个组件需要共同筛选时，配置**搜索与分类联动**。
7. 点击**预览**检查整体效果，准备好后统一**保存页面**。

| 操作或配置 | 草稿中的效果 |
| --- | --- |
| **复制组件** | 复制配置和数据绑定引用，创建新组件实例；不复制或新增来源业务记录 |
| **隐藏/显示** | 保留组件及绑定，可继续从页面结构选中；显示时会分配一个允许的可见位置 |
| **移除组件** | 移除该组件及其位置，保留来源数据和已有绑定定义 |
| **锁定位置与尺寸** | 解锁前不能移动、缩放、隐藏、复制或移除，仍可编辑内容设置 |
| **宽度** | 按网格列数调整未锁定主内容组件 |
| **高度 → 适应内容** | 使用内容高度，最少三个网格行；在周边布局允许的范围内减少固定高度内部视口 |
| **高度 → 固定高度** | 使用指定行数，内容超出时在组件内滚动 |
| **搜索框宽度** | 区域中的搜索框保持紧凑，上限 360 px |

一个页面最多 **32 个组件**和 **32 个数据绑定**，同一种组件可以添加多次。共用绑定或复制组件不会扩大权限。已绑定来源暂时不可用时会保留引用，不会偷偷切换到其他来源。

主内容区采用 **24 列网格**。宽画布中可拖动未锁定组件的标题把手移动，用右下角把手缩放，也可在属性面板中调整尺寸。排列会检查边界与已有网格占位，避免重叠；改变尺寸可能同时调整位置以腾出空间。锁定组件继续约束可用空间。

画布可用宽度不超过 900 px 时，使用窄屏排列并停用桌面拖动。这里看的是实际画布宽度，包含编辑侧栏占用空间后的结果。改变窗口大小或打开抽屉不会写回桌面坐标。已有固定高度在明确编辑并保存前保持原值。

卡片按可用列宽排列，相邻小分类可以按原顺序并排，大分类保留整行；末行仍可能有空单元格。**卡片/目录**选择排列方式，以下设置独立决定每个导航或收藏组件中的图标外观：

| 图标与文字 | 行为 |
| --- | --- |
| **跟随主题** | 使用当前主题默认值，保存时省略 `linkAppearance` 字段 |
| **图标与文字** | 在链接文字旁展示图标 |
| **简约文字** | 隐藏装饰性链接图标，保留链接文字和操作 |
| **应用图标** | 使用圆角应用图标容器，并保留链接名称 |

明确选择的图标样式在切换主题后保持不变。需要重新采用各主题默认值时，选回**跟随主题**。改变展示方式不会清除链接本身保存的图标。

需要填写精确 X/Y、网格尺寸、区域顺序或吸顶行为时，仍可使用后台**布局与主题 → 积木与数据绑定 → 高级设置**。后台一次展开一个所选组件，与首页编辑器共用页面接口和校验。

### 调整导航与收藏的组件内容

在首页点击**编辑页面**，从画布或**页面结构**选中**书签导航**或**常用收藏**，再到属性面板的**组件内容**调整。后台在**布局与主题 → 积木与数据绑定 → 选中组件 → 组件内容**提供同一组设置。这些选项只属于当前导航或收藏组件，不会修改其他组件的内容设置或布局位置。

| 控件 | 可选值与默认值 | 作用 |
| --- | --- | --- |
| **每行最多链接数** | **自动**（默认），或 **1–8 个** | 自动沿用响应式排列；指定数量是组件内部每行的上限，宽度不足时会减少。不会改变组件本身的宽度。 |
| **网址显示** | **无描述时**（默认）、**始终**、**隐藏** | 在没有显示描述时显示主网址的主机名、始终与描述一起显示，或隐藏网址。将描述设为隐藏时，也会触发默认的网址回退。 |
| **描述行数** | **1 行**（默认）、**2 行**、**3 行**、**隐藏** | 限制可见描述的最多行数；隐藏对应零行，原始描述仍保留。 |
| **标签显示** | **跟随样式**（默认）、**显示**、**隐藏** | 跟随样式沿用主题、密度和卡片/目录的既有行为；明确选显示时，目录也可展示最多前三个标签。 |
| **显示其他入口** | 默认开启 | 显示链接的内外网入口及普通附加网址。隐藏不会关闭自动选路；新页面未能打开时，仍可显示手动重试入口。 |
| **显示分组标题** | 默认开启 | 显示分类分组或收藏分组的标题；隐藏只去掉标题，保留分组及其链接，导航组件单独填写的组件标题仍显示。 |
| **显示链接数量** | 默认开启 | 在可见的组件标题或分组标题旁显示链接数量；分组标题隐藏后，其数量也不显示。 |
| **内容密度** | **跟随页面**（默认）、**宽松**、**紧凑** | 沿用页面密度，或只覆盖当前组件内容的间距与尺寸。 |

**目录**始终为单列，不显示**每行最多链接数**控件；之前设置的上限仍保留，切回**卡片**时继续使用。标签的**跟随样式**通过省略 `showTags` 字段保存，不写入继承字符串或 `null`。网址文字显示主机名，包含存在的非默认端口；悬停提示保留完整网址。

修改会立即更新当前草稿与画布/预览，支持**撤销/重做**，统一点击**保存页面**后才对普通访问生效。取消、恢复遵守其他页面设置的草稿规则。旧页面省略这些选项时沿用兼容默认值；调整组件内容不会修改书签记录。

### 设置搜索与分类联动

在所选组件的**搜索与分类联动**中选择：

| 选项 | 作用 |
| --- | --- |
| **主导航** | 预设联动组，同组搜索、分类与链接共同筛选 |
| 自定义名称 | 同名组内部共同筛选，与其他组分开 |
| **独立使用** | 当前组件独立使用筛选状态，后台标签为**独立使用，不与其他积木联动** |
| **已有分组 1**等 | 已保存但没有友好名称前缀的标识，保留原值；后台属性还可通过提示查看完整标识 |

首页编辑器点击**新建联动分组**，填写如“工作”“个人”或 `Work` 的名称，再点**创建**；后台对应按钮为**新建分组**和**创建并选择**。为相关搜索、分类和导航组件选同一组，最后保存页面。名称最多 75 个字符，相同名称会选择同一组。

联动组只控制筛选关系，不改变权限，也不复制数据，不需要填写内部英文标识。独立搜索没有其他筛选目标；要控制一块独立导航，应让搜索与目标导航使用同一命名组。首页搜索覆盖标题、描述、标签、主网址和附加入口名称/网址；选择父分类会包含后代分类的链接。

### 可视化维护页眉与页脚

1. 首页编辑时，从**页面结构**选择**页眉**或**页脚**，或者直接点击画布中的左侧、居中、右侧槽位。空区域和关闭区域在编辑时仍可选中。
2. 按需设置**显示页眉/显示页脚**，用属性面板的对齐按钮选择要编辑的位置。
3. 点击**文字**、**链接**或**标识**添加内容；添加时会开启该区域。填写文本，链接另填**链接网址**和**在新标签页打开**。
4. 选中已有内容进行修改，用上下箭头调整槽内顺序，或点击**删除内容**从草稿移除。
5. 通过**显示区域**与**对齐位置**在六个槽位间移动当前内容。如果目标区域已关闭，需要开启它才会显示移入内容。
6. 预览整页效果，使用顶部同一个**保存页面**提交主题、组件和页眉页脚。

| 内容或规则 | 限制与行为 |
| --- | --- |
| 文字 | 必填纯文本，最多 500 个字符，可换行 |
| 链接 | 必填文字最多 160 个字符，完整 HTTP/HTTPS 网址最多 2,048 个字符；网址不允许内嵌凭据、空白、控制字符或反斜线 |
| 标识 | 玉绿色折带房屋图形、项目名与版本，可移动或移除 |
| 容量 | 每个对齐槽位最多 8 项，完整页面配置最多 64 KiB |
| 关闭区域 | 内容保留，保存时继续校验 |
| 切换内容类型 | 清除新类型不接受的链接/文本字段，保留文字过长时需先缩短 |

保存会检查**全部六个槽位**，包括未选中的位置和已关闭区域。发现无效项时，编辑器会按需退出预览，定位对应区域、位置和内容，打开属性面板并聚焦错误字段；校验通过前不会发送页面更新。页眉页脚不需要另存一次。

这些字段只显示纯文本，不执行 HTML、Markdown、脚本、任意小组件或自定义 CSS。内容 ID 自动生成；外部写入方遵守相同的[页眉页脚接口契约](API.md#header-and-footer-content)。后台**布局与主题 → 页眉与页脚**仍可编辑同一份数据。

未填写 `chrome` 的旧页面兼容为空且关闭的页眉，以及开启并在右侧显示项目品牌的页脚。普通浏览中，自定义页眉是站点头部下方的额外内容行；编辑时普通头部替换为专用工具栏，预览时恢复普通头部展示。短页面页脚在视口底部，长页面页脚在内容之后，不覆盖链接。切换主题或布局预设会保留自定义页眉页脚。

### 不保存即可预览

首页编辑器点击**预览**后隐藏侧栏和选中边框，以普通首页头部展示当前草稿。点击**继续编辑**返回同一草稿和选中对象；顶部编辑工具栏仍在，可以保存、取消或返回编辑。

后台还提供按指定尺寸预览：

1. 打开**布局与主题 → 预览首页**。
2. 选择**预览分辨率**：**2560 × 1440**、**1920 × 1080**、**1600 × 900**或**2560 × 1080**。iframe 按完整逻辑视口排版后缩放，不把小预览容器当成 2K 屏幕。
3. 修改设置并观察草稿。点击**放大预览**获得更大画面，**返回编辑**或 Escape 关闭放大，**关闭预览**收起侧栏。
4. 放大预览中的**保存页面**仍走同一套页面校验和版本检查。打开或放大本身不会自动保存。

两种预览都使用已经授权的数据。匹配的数据投影会复用，新选中的可见来源可能需要读取已有快照；预览不会请求上游同步。缺失快照或筛选投影仍显示未就绪，读取失败时提供提示及重试。

预览中的搜索、分类展开使用独立内存状态，不修改页面、普通浏览偏好或链接。首页编辑及预览时，收藏写入、账号/空间切换和外链跳转不可用。离开或刷新编辑器可能丢失未保存草稿。[旧后台预览图](https://github.com/zhigege666/Lingshu-Home/blob/v0.0.1/assets/screenshots/admin-brand-preview-2k.png)是历史记录，不展示新的首页可视化编辑器或 iOS 主题。

### 保存、恢复与取消

- **保存页面**：校验后通过一次带版本检查的请求提交完整草稿，包含主题、组件、布局和页眉页脚。有改动时才可保存，首页编辑器的 Ctrl/Cmd+S 使用相同操作。
- **恢复**：恢复到进入本次编辑时的配置并保持编辑打开，不会读取服务器最新版本，也不是恢复出厂预设。
- **取消**：丢弃首页草稿，退出编辑并读取当前已保存页面；后台**取消更改**恢复当前已加载的保存版本。

可编辑画布中收起整个分类组件会改变草稿默认值，树分支和搜索仍是临时操作。保存改变的分类默认值/样式后，当前标签页只清除这些组件有冲突的整栏偏好，其他组件和访问者标签页不会被改写。

如果保存成功但随后重新加载失败，界面会明确区分，并保留已保存配置及新版本。不要直接当成写入失败反复提交。

### 处理页面保存冲突

其他窗口或客户端先保存时，Home 返回 HTTP **409 `page_version_conflict`** 并保留草稿，不自动覆盖更新的版本。

后台可先用**下载当前草稿**保留参考，再点**查看服务器版本**；只有明确选择**载入服务器版本，替换当前草稿**才替换当前内容。对照草稿将所需调整应用到新版本后保存。当前没有草稿文件导入按钮。

首页编辑冲突也会保留草稿。先记录需要的调整，再取消以读取最新保存布局并重新应用。**恢复**只回到本次本地编辑起点，本身不能解决版本过期问题；内存草稿不是持久备份。

### 哪些操作会保存

| 操作 | 持久化范围 |
| --- | --- |
| 普通首页搜索、分类选择、卡片/目录与配色按钮 | 临时浏览状态，不写页面、不请求上游同步 |
| 普通浏览中的分类整栏/树分支折叠 | 按页面和组件隔离的浏览器标签页偏好 |
| 可编辑画布中的组件/主题/页眉页脚调整、**适应内容**及分类整栏收起 | 只改内存草稿，直到**保存页面** |
| 首页预览开关、后台预览切尺寸/放大、预览中的搜索/折叠 | 只读预览及隔离的临时状态 |
| 两种编辑器的**保存页面** | 保存完整页面配置，检查页面版本 |
| **取消更改**、**取消**、**恢复** | 按上述语义改变本地编辑状态，不写页面 |
| 普通浏览时的本地链接星标 | 立即保存导航变更，要求当前空间可维护 |
| 在链接/分类表单选图标 | 表单草稿，随链接/分类保存 |
| 导入/删除图标库、获取网页图标 | 立即写入当前空间的图标库/缓存，取消链接/分类表单不会撤销 |

希望某个外观成为访问者默认值时，需要在编辑器中修改并保存页面。刷新从已保存外观开始显示；普通浏览不会清除当前标签页的分类折叠偏好。

## 6. 设置分类导航模式

首页编辑时，在画布或页面结构中选择分类导航组件，配置**分类样式**；需要多组分类时可从**添加组件**新增。后台也可通过**布局与主题 → 积木与数据绑定 → 分类导航外观**编辑。每个分类组件分别维护数据来源、联动组及顶部/左侧/右侧/底部/隐藏位置。

| 选项 | 效果 |
| --- | --- |
| 显示模式 | **图标 + 文字**、**纯图标**、**纯文字** |
| 分类层级 | **树形层级**保留可展开的父子关系；**平铺分类**逐项显示完整分类路径 |
| 显示链接数量 | 显示或隐藏分类数量 |
| 允许展开与收起 | 允许将带文字的整栏导航收起为图标栏；后台标签为**允许收起为图标** |
| 默认收起 | 没有当前页面/组件手动会话偏好时决定初始状态；后台标签为**默认收起为图标** |

默认是图标加文字、树形、显示数量、允许收起、初始展开。旧页面未填写这些新字段时使用同一默认值。纯图标本身已经紧凑，整栏收起设置不适用，但树形子分类仍可独立展开。

整栏按钮控制整个分类导航，分类旁的小箭头只控制该分类的子项，点击箭头不会顺便切换分类筛选。点击分类名称或图标才会筛选，父分类包含后代链接。当前选中子分类的祖先路径保持展开，切换到其他分类或全部链接后才能收起该路径。

纯图标提供完整可访问名称，鼠标悬停或键盘聚焦时可看到提示，Escape 可关闭提示。顶部、底部和窄屏使用单行横向分类条，可直接滚动或点溢出箭头查看后面的分类。左右侧的纯图标区域可收窄到 72 px；同侧还有其他组件时，会保留那些组件所需宽度。

普通浏览中的手动收起、展开会在当前标签页刷新后保留，按页面和组件隔离，不写入服务端，也不会替其他用户改变配置。已手动操作的标签页优先使用自己的状态，检查保存的默认值时应使用尚无该偏好的新会话。可编辑画布中整栏收起改的是未保存默认值；两种预览均使用隔离内存状态。

首页父分类数量包含绑定数据集中的后代链接；管理分类列表的数量是**直接归属**该分类的链接数，两处数字可能不同。

## 7. 接入外部数据、GitHub Traffic 和 MCP

先登录有权维护目标空间的账号。以下是操作入口，准确请求格式和权限表见 [INTEGRATIONS.md](INTEGRATIONS.md)。

### “组件数据格式”在哪里新增

**数据源与 MCP → 数据源 → 添加数据源 → 组件数据格式**用于选择来源输出的数据契约，不是新增组件类型，也不是注册自定义格式。通用数据源表单提供五种内置选项：

| 格式 | 协议 ID | 对应显示组件 |
| --- | --- | --- |
| 导航书签 | `navigation.collection@1` | 导航、分类与收藏 |
| 日程 | `calendar.events@1` | 日程/议程 |
| 天气 | `weather.forecast@1` | 天气 |
| 统计指标 | `metrics.summary@1` | 指标卡片 |
| 服务状态 | `status.collection@1` | 服务状态 |

定时读取 JSON 的来源支持后四种组件格式，不支持导航书签。GitHub Traffic 使用独立来源类型与 `github.traffic@1`，不会作为通用下拉框里的新增格式。可以创建多个使用同一格式的数据源；已创建来源不能直接改变数据格式。

表单说明这些格式为内置格式，并可展开当前格式的 JSON 数据示例。外部推送来源创建后，打开**推送模板**，在外部程序中替换样例并推送快照，再给首页的兼容组件绑定来源并保存页面。定时 JSON 来源的地址应直接返回所选格式的 `data` 对象。真正增加新协议需要开发服务端校验、兼容渲染器和能力声明；没有后台“新增格式”按钮，导入组件模板也不会安装新格式。[组件契约](COMPONENTS.md)与[来源配置](INTEGRATIONS.md#source-configuration)提供具体字段。

### 外部推送导航

1. 进入**数据源与 MCP → 数据源 → 添加数据源**。
2. 选择**外部推送 / 日程文件导入**，组件数据格式选择**导航书签**，填写名称后创建。
3. 打开**MCP 与访问令牌**，创建一个仅授权该数据源的令牌。界面会为此范围授予读取源和推送快照能力；令牌原文只显示一次，及时保存。
4. 回到数据源，打开**推送模板**，在外部程序中替换示例数据和令牌。
5. 推送完整快照，附带唯一请求 ID 和版本/递增序号条件。完全相同的重试使用原请求 ID；数据改变后使用新请求 ID。
6. 成功后查看**快照**，再到布局编辑器给导航积木绑定这个源，保存页面。

一次推送会替换该外部源自己的快照，不会合并进**链接管理**，也不会覆盖本地书签。空集合也代表一次有效的整体替换。协议支持最多 10,000 条链接、5,000 个分类和 8 MiB 的规范化快照 JSON；重放、冲突和数据格式详见[推送协议](INTEGRATIONS.md#push-protocol)。

### GitHub 仓库流量

1. 新建 **GitHub Traffic · 仓库流量**数据源，填写仓库所有者、仓库名称和具有该仓库 Traffic API 权限的 GitHub 令牌。
2. 创建后，若需要立即排队采集，可点**采集基线**。新建源也会启用定时采集，默认每六小时一次。
3. 等待状态变为**已有快照**，并检查**最近成功**。显示“正在采集”只表示排队或执行中，不代表已经取得 GitHub 数据。
4. 到**布局与主题**添加 GitHub Traffic 积木，选择数据源并保存。
5. 需要时用**重新采集**排队更新；更换凭证时打开**配置**填写新令牌，已有凭证留空表示保留。

首次 views 与 clones 都成功的采集建立不可覆盖的基线，以后持续保存 UTC 每日观测。滚动窗口对比不是累计总流量，缺失观测不会当成零；采集失败保留上一次成功快照。Git SSH 授权不等于 GitHub API 令牌，权限和指标口径见 [GitHub Traffic 说明](INTEGRATIONS.md#github-traffic)。

已有首个快照的源不能直接换成另一个仓库，需要另建数据源。源配置可停用并保留数据，当前没有数据源删除入口。Home 默认不附带真实仓库凭证或真实流量基线。

### Home 访问令牌与 MCP 客户端

在**MCP 与访问令牌 → 创建令牌**中填写客户端名称，选择当前空间或单一数据源范围、需要的操作，并在界面提供的 7、30、90 天中选择有效期。单源令牌适合一个外部推送程序；维护本地书签或页面时选择当前空间范围。

在支持 **Streamable HTTP** 的 MCP 客户端中填写页面显示的 `/mcp` 地址，并通过 `Authorization: Bearer <Home 令牌>` 请求头认证。这里使用 Home 签发的令牌，与 GitHub 数据源令牌不同。客户端需要支持此请求头；Home 没有提供仅 OAuth 登录式的接入。由客户端发现工具及参数，然后调用授权范围内的操作。

令牌原文仅创建时显示，之后可以在列表中撤销，客户端随即失去权限。改变访问模式会使旧会话、旧令牌失效；停用或重置某个成员也会撤销该账号的既有访问。PAT 不能创建账号、修改全局安全设置或签发更多令牌。完整范围和协议示例见 [MCP 传输说明](INTEGRATIONS.md#mcp-transport)。

## 8. 成员与访问设置

Owner 在**访问与账号**中修改站点名和模式；选多人空间时，可以另外开启**允许访客自行注册 Member 账号**。保存后如当前会话失效，需要重新登录。切换模式不会删除成员个人空间，也不会将其自动公开。

多人模式下，进入**成员管理 → 创建成员**，填写用户名、显示名与初始密码，成员即可登录自己的空间。点**编辑**可修改显示名、启停账号或填写新密码。**重置密码**留空表示保留原密码；停用或重置会使该账号既有访问失效。当前没有成员删除、邮件找回密码的界面。

Owner 维护共享空间和自己的个人空间，不能查看 Member 的私人页面。Member 可浏览共享内容，但不能维护共享空间。缺少编辑按钮时，先检查当前空间及访问模式。

## 9. 导出、备份与重启

### 导出当前空间

**导入与导出 → 导出 HTML**生成浏览器书签文件；**导出 JSON**包含本地链接、分类、空间与页面配置。JSON 不包含账号、外部数据源凭证、外部快照，以及导入图标库的图片二进制和元数据。两种导出都不是完整实例备份，JSON 也不是一键恢复或 SQLite 转 PostgreSQL 的工具；自定义图标引用需配套原数据库中的图片才能显示。

### 保存数据库与密钥

完整备份按 [STORAGE.md](STORAGE.md#backups) 操作。SQLite 最直接的方式是正常停止 Home，备份完整持久化目录/卷，包括两个密钥以及可能残留的 WAL 文件。PostgreSQL 需要将专属数据库和对应的本地密钥一起备份。恢复时使用匹配的应用版本，并只启动一个实例。

自定义图片、图标库元数据、网站缓存、自动开关和待办都在数据库中，没有额外上传目录。0.0.1 包含自动图标的**迁移 005**与网络设置的**迁移 006**；0.0.2 增加固定实例语言的**迁移 007**，完整数据库备份也保留所选语言。不认识已应用迁移的旧程序会拒绝升级后的数据库；回退必须恢复匹配的升级前数据库与密钥，并使用原程序/镜像。

README 正式镜像命令使用 **`lingshu-home-data`** 命名卷；源码 Compose 使用属于该项目的 **`home-data`** 卷。重启或替换容器时保留原卷及 Compose 项目身份，不能把换安装方式当成自动迁移。Linux 发行包继续使用原 `--data-dir`，而不是新版本目录下的空白 `data/`。删除卷会删除持久数据，不要将移除卷当成重启方式。导出文件、完整备份和凭证文件都应保持私有。

### 重启并检查服务

README 正式镜像部署：

```bash
docker restart lingshu-home
docker ps
docker logs --tail=100 lingshu-home
curl -fsS http://127.0.0.1:5180/health
```

备份前后使用 `docker stop lingshu-home` 和 `docker start lingshu-home`，保留 `lingshu-home-data` 卷。镜像示例的停止等待时间为 30 秒。

源码 Compose 部署：

```bash
docker compose restart home
docker compose ps
docker compose logs --tail=100 home
curl -fsS http://127.0.0.1:5180/health
```

使用外置 PostgreSQL 的部署，要一致使用 `docker compose -f compose.postgres.yaml`，并保留原来的私有环境配置。备份前后可以分别用 `docker compose stop home` 和 `docker compose start home`；停止服务本身不会删除数据卷。

Linux 发行包前台运行时，按 `Ctrl+C` 并等待退出；然后在发行包目录使用原语言和固定数据目录启动，例如：

```bash
./lingshu-home --language zh-CN --data-dir "$HOME/.local/share/lingshu-home"
```

如果由 Linux 开发启动脚本管理：

```bash
python3 scripts/dev.py stop
python3 scripts/dev.py start --language zh-CN
python3 scripts/dev.py status
```

重启时保留原 provider 和数据目录参数。上例保留显式中文参数；从 0.0.1 首次升级时，应保留原语言配置，使用英语的实例尤其需要明确 `en`。0.0.2 已经保存语言后，即使省略参数也以数据库保存值为准。重启不会自动编译新源码。更新源码时，先保留可恢复备份和旧版本，按 README 构建，再用同一个数据目录及数据库 provider 重新启动。降级前查看[迁移与恢复规则](STORAGE.md#versioned-migrations)。

Linux 开发启动脚本允许在旧连接等待 TCP 超时期间立即重启。真正仍被运行中服务监听的端口会继续报错；启动另一个实例前，先检查 `status` 和指定的监听地址。

## 10. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 其他设备打不开 | 默认端口只在宿主机回环地址开放，检查对外地址、端口发布和代理；其他设备上的 `127.0.0.1` 是那台设备自己。 |
| 已用过的实例重新要求初始化 | 先检查数据库 provider、数据目录和卷是否指向原来位置，确认持久化配置后再决定是否初始化。 |
| 后台好像少了内容 | 检查当前空间、搜索、分页和首页分类筛选。后台本地链接管理不依赖首页把数据绑定叫什么名字。 |
| 后台有链接，首页不显示 | 检查是否存在可见导航积木、数据来源是否正确，清除分类/搜索/收藏筛选，检查固定高度积木内部是否还有内容。 |
| 页面保存失败 | 阅读内联错误，检查版本冲突、网格越界/重叠及锁定状态；拒绝保存时草稿保留。 |
| 语言没有变化 | 0.0.2 保存语言后不再切换，冲突启动值会被忽略并记录警告，这是预期行为。已有名称保持原文。 |
| 预览与已保存首页不同 | 检查未保存标记及临时筛选；预览跟随当前编辑草稿，其他访问者看到的是保存配置。 |
| 换主题后某个组件图标样式不变 | 该导航/收藏可能明确选择了**图标与文字**样式，改回**跟随主题**并保存页面即可使用主题默认值。 |
| 无法添加、复制或移动组件 | 检查锁定、32 个组件/绑定上限和允许位置；Traffic 先创建兼容来源，分类不能放在主内容网格。 |
| 预览提示部分数据未就绪 | 检查绑定及来源快照；缺失筛选投影不会被伪造，读取失败可点重试。 |
| 看不到页脚内容 | 检查页脚显示开关、所选对齐位置及未保存状态；长页面的页脚在完整内容之后。 |
| 关闭的页眉页脚项仍阻止保存 | 关闭区域会保留并校验其内容；按错误定位填好或移除无效项，再保存。 |
| 无法删除分类 | 先移走直接归属的链接和子分类。 |
| 无法删除图标库 | 先替换仅由该库保留的已保存图片引用，链接、分类、页面配置和外部快照都会检查。 |
| 无法获取网站图标 | 检查实例开关和链接模式，后台获取完成后刷新列表；0.0.4支持服务端可达的公网/内网 HTTP/HTTPS 与自定义端口，需检查服务端 DNS、网络、HTTPS 证书和图片格式；初次失败缓存 30 分钟。登录后可见或复杂图标可导入 PNG 或使用预制图标。 |
| 取消链接编辑后仍有导入的图标 | 图标库导入/删除及网站缓存会立即保存，取消只放弃表单中的图标选择。 |
| 书签预览只有 200 行 | 这是预览显示上限，统计仍覆盖整个文件。 |
| 导入拒绝文件或网址 | 使用 UTF-8 浏览器 HTML 导出，控制在 2 MiB / 10,000 条以内；只支持 HTTP/HTTPS，同时检查目标分类加文件夹的最终深度。 |
| 默认收起没有改变当前页 | 手动会话偏好优先。直接切换整栏状态，或在尚无偏好的新会话中检查默认配置。 |
| 数据源没有数据 | 检查配置、状态和快照；推送源需要首次成功推送，Traffic 需要有权限的采集，并且首页绑定格式匹配。 |
| MCP 或推送客户端突然失效 | 检查过期、撤销、账号状态、模式变化和授权范围；需要时由已登录账号创建替代令牌。 |
| 复制按钮失败 | 手动选中文字复制；自动剪贴板能力受浏览器来源和安全规则影响。 |
| 登录失败或被限流 | 检查账号和模式，出现限流时按提示等待重试，不要换接口绕开限制。 |
| 服务存储不可用或启动失败 | 查看日志、目录权限、数据库连接和单实例锁。PostgreSQL 锁连接丢失时恢复连通后受控重启，不要让多个实例竞争同一数据库。 |

大量链接时，可以先用分类/搜索缩小首页内容，选择目录或紧凑密度，后台使用较小的每页数量。这些选项减少展示负担，但不会把现有快照 API 变成后端分页，也不等于承诺某个加载耗时。报告性能问题时，请带上数据数量、浏览器、窗口尺寸和具体操作。

## 11. 当前能力边界与其他资料

## 日程、天气和其他数据组件

先进入**管理中心 → 集成**配置数据来源，再给日程、天气、统计指标或服务状态组件绑定来源。ICS 订阅会定时读取加密保存的 HTTP/HTTPS 地址；一次性 ICS 文件导入使用日程推送来源，替换该来源当前有限时间窗的快照。私人日程使用个人空间；放在共享空间的事件标题、地点等内容遵循该空间的浏览权限，订阅 URL 和密钥只保存在服务端。

天气可选城市快捷项，也可手动填写经纬度与 IANA 时区，再按使用场景选择免费非商业服务或带 API key 的商业服务。保存启用的轮询来源后，服务端排队采集；**同步**也是排队请求，实际结果看最后成功时间和错误状态。首页的**更新数据**读取已有缓存，不强制请求第三方。停用来源才停止采集，已成功数据会保留；隐藏组件只改变布局。

在**编辑页面 → 添加组件**中选择兼容组件，或点**导入组件模板**，粘贴公开的组件地址/JSON，也可选 JSON 文件。先查看渲染类型、版本、许可、来源，再选择本机数据来源。应用后只是页面草稿，可以排版、预览，最后**保存页面**才持久化。取消、恢复或离开有未保存修改的页面时，需要明确放弃草稿。普通网页没有声明受支持模板时，不能直接当作可执行组件导入。

完整数据字段、供应商限制、存储与重放策略、模板格式和暂未内置的连接器见 [COMPONENTS.md](COMPONENTS.md)。首次配置预览与保存语言匹配的网站包，也可关闭示例并从空白导航开始。


## 网络设置与内外网访问

在后台打开“网络设置”。自动选择内外网入口默认开启，保存只改变选路偏好。编辑书签时，在“网络入口”中为内网和外网分别填写地址；普通附加链接继续用于文档、后台等手动入口。探测路径留空使用 `/favicon.ico`，也可填写无需登录、只读的 `/healthz`。点击书签后最多等待约 800 毫秒；内网未确认响应时回到外网或主入口。手动入口始终可以直接选择。

首页打开、悬停和闲置不会探测网络。跨域的探测路径需要允许 Home 读取响应；网站图标未开放跨域读取时，可在目标服务或反代配置公开、只读的健康路径，也可使用手动入口。浏览器还可能需要局域网权限或阻止请求；未检测到响应不等于服务离线。结果仅存在浏览器短期内存中，网络变化或刷新会重新判断。

Owner 可在同页指定服务端 HTTP、HTTPS 或 SOCKS5 代理及独立凭据。代理作用于 Home 获取图标、模板和来源数据；地址按 Home 服务或容器的网络解释。凭据加密保存、不会回显。更换代理地址时需要重新填写或明确清除旧凭据。保存不会测试代理；代理服务还需支持向目标端口建立 CONNECT 隧道（包括 HTTP 的 80 端口）。[完整协议、恢复和限制](NETWORK.md)。

## 从网页选择组件模板

在首页编辑器选择“导入组件模板”，输入网页或 JSON 地址。网页需在 head 中声明兼容的 Home 模板；有多个声明时先选一个再检查。预览会显示组件类型、版本、许可、数据格式和来源。失败会保留输入，可修改重试或停止读取。

“模板示例与网页声明”提供七种组件示例，可直接填入或下载 JSON。选择兼容来源后加入页面草稿；缺少来源时，登录用户可在原流程创建兼容来源，再回到保留的预览。来源立即保存到空间；组件仍需要加入草稿并通过“保存页面”生效。模板 URL 是随页面共享/导出的公开溯源，请将私密订阅地址放入独立数据源配置。

## 从预置仪表板开始

打开**编辑页面 → 添加组件 → 预置仪表板**。**个人概览**组合天气、日程和书签；**服务运行**组合服务状态、资源指标和操作入口；**数据统计**组合两组指标、可选 GitHub Traffic 和参考链接。布局缩略图只显示组件名称，不填入演示数值，也不启动数据采集。

为每个勾选的组件选择已启用、格式匹配的来源。显示**待绑定**的组件需要选好来源，或取消勾选，才能应用。尚无首次快照的来源也可绑定，组件会显示正常的等待数据状态。书签和收藏沿用既有兼容来源、筛选条件和联动组；更换来源时不携带旧来源的筛选。两组统计指标选同一来源会完整显示同一组数据，界面会明确提示。

**替换当前草稿布局**只改变未保存的排布，并保留主题、配色、页眉页脚和搜索/分类设置。之后**保存页面**才会持久化，也可用编辑器的取消/恢复放弃草稿。在向导中创建来源会立即保存来源，这是独立操作。隐藏、跳过或移除组件不会停用已有的轮询来源；需要停止采集时，请停用来源本身。

[仪表板说明](DASHBOARDS.md)列出每个组件槽位，[数据交接样例](../examples/dashboard-data/README.md)提供八份经过校验的推送请求和契约索引，供后续适配器使用。样例的固定日期及未知值只用于开发，不会自动安装成实时数据。
